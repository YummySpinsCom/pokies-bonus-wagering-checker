# Pokies Bonus Wagering Checker

A simple browser-based tool for reviewing common online pokies bonus conditions.

The tool helps players quickly calculate the wagering requirement attached to a bonus and understand how maximum bet limits and cashout caps affect the promotion.

## What the tool calculates

Enter:

- Bonus amount
- Wagering requirement
- Maximum allowed bet
- Cashout cap

The tool will calculate:

- Total wagering required
- Approximate number of maximum-size bets required to complete wagering
- Maximum cashout based on the entered bonus terms

## Example

For a NZ$100 bonus with a 35x wagering requirement:

**NZ$100 × 35 = NZ$3,500**

If the maximum permitted bet is NZ$5, completing NZ$3,500 of wagering would require at least 700 bets at the maximum bet size.
